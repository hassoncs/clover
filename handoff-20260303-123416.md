## 3. The Blocking Problem

### Error: `ReferenceError: await is not defined`

When loading ANY page in the Pencil web app (including the existing index route, not just waypoint), the app crashes with:

```
ReferenceError: await is not defined
  at eval (eval at <anonymous> (...))
  at fetchThenEvalJs.ts:26
```

This is **not caused by our migration or waypoint code**. It happens on the index page too. It's an Expo/Metro bundler issue where a lazily-loaded module contains a top-level `await` that the `eval()` context in `fetchThenEvalJs.ts` doesn't support.

**Root cause hypothesis:** The `TRPCProvider` in `_layout.tsx` imports `AppRouter` type from `@slopcade/api/trpc`, which transitively pulls in runtime modules that use top-level `await`. Metro's lazy loading evaluates these via `eval()` which doesn't support `await`.

### What Was Tried

1. **Lazy-loading TRPCProvider via dynamic import** — Changed `_layout.tsx` to use `import("../lib/trpc/client")` in a `useEffect`. The import itself still triggers the eval error because Expo's async require system intercepts it.

2. **Taking screenshots with various tools:**
   - `agent-browser` — Chrome CDP kept dying/disconnecting
   - `browser-use` cloud browser — can't reach `localhost:8089` (it's a remote browser)
   - Playwright headless — successfully takes screenshots but they show the error overlay
   - Tried dismissing the error overlay programmatically — session timed out

### What Was NOT Tried

- **Checking if this error exists on the main branch** — it might be a worktree-specific issue (missing node_modules, different Expo version, etc.)
- **Running `pnpm install` fresh in the worktree** — might fix module resolution
- **Using `expo start --web --no-dev`** (production mode) — might handle top-level await differently
- **Removing the TRPCProvider entirely** from `_layout.tsx` (the waypoint route doesn't need it)
- **Creating a standalone HTML page** that loads the Skia WASM renderer directly without Expo Router
- **Testing on iOS simulator** instead of web — Skia works natively, no eval issues
- **Checking if the main Slopcade app's web build works** — to isolate whether this is a pencil-app-specific or monorepo-wide issue

### Architecture
The rendering pipeline is:
```
waypoint.json → loadPenFile(json) → SceneGraph (476 nodes)
  → sceneGraphToPenDocument() → PenDocument
  → PenRenderer receives PenDocument:
    1. buildComponentRegistry() — finds reusable components
    2. resolveAllRefs() — expands ref nodes to inline copies
    3. resolveTreeVariables() — resolves $-- variable references
    4. layoutTree() — Yoga WASM layout computation
    5. Renders via Skia Canvas (react-native-skia)
```
