# Generative UI Builder Animations

## TL;DR

> **Quick Summary**: Add theatrical "build" animations to the Pencil canvas when the AI generates new UI elements, including a multi-agent cursor system, glowing construction borders, and physics-based entrance choreography.
> 
> **Deliverables**:
> - Updated `PenNode` schema with `createdAt` timestamp.
> - Upgraded `MultiplayerOverlay` with bezier cursor movement and states.
> - Skia-based `BuildAnimationChrome` that adds glowing, drawing borders to new nodes.
> - Entrance animations (scale, fade, translate) for new Skia nodes based on age.
> 
> **Estimated Effort**: Large
> **Parallel Execution**: YES - 3 waves
> **Critical Path**: Task 1 (Schema) -> Task 2 (Ops Injection) -> Task 3 & 4 (Rendering & Cursors) -> Task 5 (QA)

## Context

### Original Request
Add the "Generative UI Builder" experience: multi-agent cursor choreography, glowing construction borders, and element entrance physics (scale, fade) based on a new `createdAt` timestamp on nodes.

### Interview Summary
**Key Discussions**:
- The tool creates JSON blobs (nodes).
- We need to detect fresh nodes and animate them.
- `createdAt` is the agreed mechanism to track "freshness" for the state machine.

**Research Findings**:
- Pencil uses `@shopify/react-native-skia` for rendering the canvas (DOM is not used for nodes).
- Nodes are defined in `@slopcade/shared/src/types/pen.ts` (`PenEntityBaseShape`).
- Cursors are rendered in `packages/design-canvas/src/panels/MultiplayerOverlay.tsx`.
- Node creation primarily happens in `applyDesignChatOpsToDocument` in `apps/pencil/lib/designChatOps.ts`.

### Metis Review
**Identified Gaps** (addressed):
- **Skia Animation Performance**: Added a guardrail to ensure Skia animations (borders, scale) don't trigger full React re-renders at 60fps, but rather use Reanimated shared values or localized Skia redraws.
- **Text Typewriter Complexity**: Typewriter in Skia is hard to measure dynamically. Guardrail added: Start with whole-node entrance (fade/scale), then evaluate typewriter feasibility.

## Work Objectives

### Core Objective
Bring the canvas to life when the AI agent generates UI, making it look like a team of agents is physically constructing the interface.

### Concrete Deliverables
- `createdAt` field on `PenEntityBaseShape`.
- `applyDesignChatOpsToDocument` setting `createdAt = Date.now()`.
- `MultiplayerOverlay` with spring/bezier cursor paths and click/hover states.
- `BuildAnimationChrome` component in `PenRenderer.tsx` using Skia `DashPathEffect` and `DropShadow` for glowing borders.
- Entrance animations (scale 0.95 -> 1.0, opacity 0 -> 1) applied to new nodes via Skia transforms.

### Definition of Done
- [ ] Nodes generated by the chat agent animate in with a glowing border and scale/fade entrance.
- [ ] Fake agent cursors move smoothly to the insertion points with a ripple/click effect.

### Must Have
- Animations must execute entirely within the Skia canvas for nodes (no HTML DOM overlays for the nodes themselves).
- `MultiplayerOverlay` must use Reanimated or React Native Animated for performance.

### Must NOT Have (Guardrails)
- Do NOT convert Skia nodes to DOM/HTML nodes.
- Do NOT trigger full React tree re-renders at 60fps for the border animation. Use Skia's optimized animation loops or Reanimated shared values.
