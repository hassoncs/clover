## T7: Primary Read Success Path

### Function: loadContentPackFromDB (api/src/party/content/prompt-loader.ts)

Primary read path (no fallback triggered):

1. Caller invokes `loadContentPackFromDB(type, brandId, db)` where `type` is a canonical ContentType
   (e.g., `"estimation"`, `"trivia"`, `"quip"`).

2. D1 query executes:
   ```sql
   SELECT body FROM party_content
   WHERE brand_id = ? AND content_type = ? AND status = 'active' AND deleted_at IS NULL
   LIMIT 2000
   ```
   bound with `(brandId, type)`.

3. `result.results` is non-empty (at least one active row exists for the canonical type).

4. The function returns `rows.map(row => JSON.parse(row.body))` directly —
   no fallback code is executed, no console.warn is emitted.

### When this path fires:
- DB has been migrated (T8) so all `wager`/`history` rows are renamed to `estimation`.
- OR DB was seeded with canonical `estimation` rows from the start.
- This is the steady-state path after the migration completes.

### Observable signal:
- No `[party-content]` warning in logs.
- Content is returned normally.
