## Tier C (Deferred)
| Name | Reason for Deferral |
|------|----------------------|
| LightPillar | Heavy raymarch (`MAX_ITER` up to 80 plus nested wave loop), many quality tiers, expensive for mobile post stack without dedicated perf budget. |
| PixelSnow | 128-step voxel/grid traversal per pixel with many branches and hashes; high overdraw and frame-time risk as a fullscreen effect. |
| Dither | Composite pipeline (`EffectComposer` + custom post effect) rather than one standalone fragment shader; requires multipass infrastructure. |
| LaserFlow | Very large shader with derivative extension path and many tuning uniforms; high complexity and browser-specific fog tuning makes first-pass Godot parity expensive. |
