# Task 7: Add new-system automated tests and remove obsolete legacy tests

## Summary

Added comprehensive unit tests for the canonical EffectDispatcher and fixed pre-existing test issues.

## New Tests Added

### EffectDispatcher.test.ts (25 tests)

#### Tag-driven effect activation (6 tests)
- `applies and clears effects from hasTag condition`
- `activates effect when entity has any of the specified tags (hasAnyTag)`
- `activates effect only when entity has all specified tags (hasAllTags)`
- `activates effect when entity lacks specified tag (lacksTag)`
- `evaluates expression conditions (expr)` - falsy case
- `evaluates expression conditions with truthy result` - truthy case

#### Script API effect operations (7 tests)
- `updates params by diff instead of reapplying`
- `script effects override declarative effects`
- `clearing script effect falls back to declarative`
- `supports multiple script effects with latest winning`
- `clears all script effects when no effectId provided`
- `returns empty string for non-existent entity`
- `supports custom effect ID via params.id`

#### Entity lifecycle (3 tests)
- `clears effects when entity is destroyed`
- `tracks entity count correctly`
- `clears all effects on dispatcher destroy`

#### Color normalization (3 tests)
- `normalizes hex color to RGB tuple`
- `normalizes RGB tuple 0-255 to 0-1`
- `preserves already-normalized RGB tuple`

#### Precedence rules (3 tests)
- `entity effects override prefab effects`
- `higher priority effect state wins`
- `script effects have highest precedence`

#### Diffing behavior (3 tests)
- `reapplies when effect type changes`
- `reapplies when param is removed`
- `updates individual params when only values change`
