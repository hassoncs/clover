- **WireframeModeProvider**: Implemented a lightweight, in-memory React context for structural mode state.
  - `mode`: "structural" | "production"
  - `selectedScreenIndex`: number
  - `totalScreens`: number (derived from document)
  - `previewConfig`: { orientation: "portrait" | "landscape", aspectRatio: string }
  - Exports `useWireframeMode()` hook with `mode`, `setMode`, `toggleMode`, `selectedScreenIndex`, `setSelectedScreenIndex`, `totalScreens`, and `previewConfig`.
  - Follows the pattern of `EditorProvider` but simplified (no reducer, just useState/useMemo).
