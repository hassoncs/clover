# Decisions

## 2026-02-13 Architecture Decisions
- Web desktop: Dockview for full VS Code-style docking
- Native tablet/iPad: react-native-resizable-panels for two-panel horizontal split only
- Native phone: unchanged (bottom sheets)
- Panel Registry pattern: shared component map used by all three layout strategies
- No layout persistence on native (only web)
- No docking/floating panels on native
