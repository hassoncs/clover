## Stripe (Web Subscriptions)

Stripe handles individual subscriptions (Amen+ monthly/yearly) and church organization subscriptions. The API reads these from Cloudflare Workers environment secrets.

### Products to Create

Go to [Stripe Dashboard → Products](https://dashboard.stripe.com/products)

#### Individual Subscriptions

| **Amen+ Yearly** | $39.99/yr | Yearly | `STRIPE_PRICE_ID_AMEN_YEARLY` | `api/src/trpc/routes/billing.ts` line 160 | `price_1T1tqBJRGbUvC8EByUmeaZxs` | `price_1T1u14JRGbUvC8EBtj34t2Id` |
| **Slopcade Pro Monthly** | $9.99/mo | Monthly | `STRIPE_PRICE_ID_PRO_MONTHLY` | `api/src/trpc/routes/billing.ts` line 162 | `price_1T1tqCJRGbUvC8EBWRK5xvJT` | `price_1T1u15JRGbUvC8EBNwDy5HVt` |

### Stripe API Keys

Set these via `wrangler secret put <KEY>`:

| Secret | Where to find | Status |
|--------|---------------|--------|
| `STRIPE_SECRET_KEY` | [Stripe Dashboard → API Keys](https://dashboard.stripe.com/apikeys) → Secret key | [ ] Set |
| `STRIPE_PUBLISHABLE_KEY` | Same page → Publishable key | [ ] Set |
| `STRIPE_WEBHOOK_SECRET` | [Stripe Dashboard → Webhooks](https://dashboard.stripe.com/webhooks) → Signing secret | [ ] Set |

### Stripe Webhooks to Configure

Create at [Stripe Dashboard → Webhooks](https://dashboard.stripe.com/webhooks)

| Endpoint URL | Events | Purpose |
|-------------|--------|---------|
| `https://slopcade-api.hassoncs.workers.dev/webhooks/stripe` | `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_succeeded`, `invoice.payment_failed` | Individual subscription lifecycle |
| `https://slopcade-api.hassoncs.workers.dev/trpc/billing.stripeOrgWebhook` | `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted` | Church org subscription lifecycle |

### How to Set Secrets

```bash
# From the api/ directory:
cd api
npx wrangler secret put STRIPE_SECRET_KEY
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put STRIPE_PRICE_ID_AMEN_MONTHLY
npx wrangler secret put STRIPE_PRICE_ID_AMEN_YEARLY
npx wrangler secret put STRIPE_PRICE_ID_PRO_MONTHLY

# For the app (Expo):
# Set EXPO_PUBLIC_STRIPE_PUBLISHABLE_KEY in your EAS build secrets or .env
```

## RevenueCat (iOS & Android In-App Purchases)

RevenueCat sits between your app and Apple/Google, handling receipt validation, entitlements, and cross-platform subscription sync. The webhook at `api/src/routes/webhooks/revenuecat.ts` processes events.

### RevenueCat Project Setup

1. Go to [RevenueCat Dashboard](https://app.revenuecat.com/) → Create Project
2. Project name: `amen-games`
3. Add platforms: iOS + Android

| Config | Value | Status |
|--------|-------|--------|
| RevenueCat API Key (iOS) | `appl_________________` | [ ] Created |
| RevenueCat API Key (Android) | `goog_________________` | [ ] Created |
| RevenueCat Webhook URL | `https://slopcade-api.hassoncs.workers.dev/webhooks/revenuecat` | [ ] Configured |
| RevenueCat Webhook Secret | (auto-generated by RevenueCat) | [ ] Set in Workers secrets |

### RevenueCat Entitlements

Create one entitlement that unlocks premium:

| Entitlement ID | Description |
|---------------|-------------|
| `amen_plus` | Full access to all games, no session limits |

### RevenueCat Offerings

Create a "default" offering with these packages:

| Package | Entitlement | Maps to App Store/Play Store product |
|---------|-------------|--------------------------------------|
| `$rc_monthly` | `amen_plus` | `amen_plus_monthly` (see below) |
| `$rc_annual` | `amen_plus` | `amen_plus_yearly` (see below) |

### RevenueCat Secrets

```bash
cd api
npx wrangler secret put REVENUECAT_WEBHOOK_SECRET
```
